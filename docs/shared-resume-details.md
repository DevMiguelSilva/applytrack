# Shared resume details

The CV library retains resolved CVs in `cvs` for existing matching, tailoring, and database guards. Contact, education, projects, and certifications are copied to each resolved CV when saved. `sharedDetails.roles` holds reusable role facts; each profile's experience list selects role IDs and retains its own bullets. Removing a role from a profile does not delete the reusable role. Existing roles are assigned distinct IDs at migration, even when their text matches, to avoid merging ambiguous records.

On first load, the Power Platform profile is identified by its legacy ID or a unique matching profile name. If it cannot be identified, loading stops. The original document is kept in `sharedDetails.original` and can be downloaded from the CV library to compare and manually recover prior differences. Local migration also stores the original under `applytrack-master-cv-before-shared-v1` before writing; a conflicting backup stops migration. Cloud migration first writes and verifies `sharedMigrationBackup` using the current revision, then conditionally writes the migrated document. A failed second write leaves that backup in the cloud document for retry. No database schema migration is required.

The editor warns which sections affect all profiles, permits choosing existing roles, and stages imports for review before saving. Library revision checks reject stale drafts, and import results are discarded after an account or library change. The backup may contain personal resume data and should be handled accordingly. Do not open an older application version against a migrated library: older versions do not understand the shared metadata and could discard it. Submitted documents continue to use their stored snapshots.
