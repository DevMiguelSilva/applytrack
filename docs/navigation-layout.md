## Behavior

Desktop navigation starts at 1024px. A fixed, scrollable sidebar reserves 240px when expanded and 72px when collapsed; content and footer keep their existing width limits within the remaining area. The default is expanded. `applytrack-sidebar-collapsed` stores the browser preference; blocked/full storage leaves the current in-memory toggle usable. Collapsed destinations, branding, sync status and account/toggle controls retain accessible names and hover/focus labels.

Below 1024px, the header contains branding only. The floating bottom bar has Board, Portals, Inbox (with count) and More. More highlights for Add/CVs and opens a native modal dialog containing those destinations and the existing conditional account/sync controls. Local mode omits cloud/account controls. Login renders branding and login content without application navigation.

After user review requested a stronger mobile design, the dock was refined to a centered 440px maximum width with four equal targets, selected-icon pills and a high-contrast Inbox badge. The mobile shell uses balanced branding and a light green-tinted canvas. More uses a 520px maximum-width workspace tray with a handle, distinct Add application/CV library cards and a separate conditional account panel. A short entrance animation respects reduced motion. Floating offsets/padding reserve seven rem plus the safe-area inset below 1024px. This navigation checkpoint preceded the shared-styling follow-up documented above.

The sheet uses the browser top layer and modal inertness, explicit forward/reverse Tab wrapping, initial close-button focus and Escape/backdrop/close dismissal. Ordinary dismissal restores More focus. Route/account changes and entering desktop layout close it and release body scroll lock. Clicking the sheet scrollbar is not a backdrop dismissal. Sheet height is bounded and scrollable, with safe-area padding. Sidebar preference survives resizing.

TailoringProvider and route/provider composition are unchanged. Floating notification and scroll-to-top offsets share the 1024px breakpoint; Back to top moves to the left of the content to avoid overlapping notifications on the right. It uses instant scrolling when reduced motion is requested. UI motion respects reduced-motion settings. No API calls or migrations are added.
